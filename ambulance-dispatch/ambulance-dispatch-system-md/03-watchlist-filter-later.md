## Quick filtering rules for later

Keep a repo if it has:
- clear incident state handling
- actual routing or allocation logic
- hospital capacity logic
- real API or dashboard boundaries
- enough code structure to verify claims

Drop or demote a repo if it is:
- mostly README pitch
- purely academic with no operational flow
- only a UI mock
- only nearest-hospital lookup with no capacity logic
- only traffic signal hardware with no dispatch model
